# TheDiscordList

[TheDiscordList](https://thediscordlist.com) is a directory of Discord servers and bots.
These are the official integrations for bot developers: each one posts your bot's server
count, cluster heartbeats and slash commands to your listing automatically, and verifies
the webhooks TheDiscordList sends you.

endpoints and an HMAC-signed webhook, so any language works.
